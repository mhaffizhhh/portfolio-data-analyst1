# Blok B — Analisis Customer

## Business Questions
1. Berapa jumlah customer baru yang acquired setiap bulannya?
2. Berapa persen customer yang melakukan repeat order?
3. Seberapa baik platform mempertahankan customer baru di bulan berikutnya?
4. Berapa Customer Lifetime Value (CLV) tiap customer?
5. Berapa persen customer yang sudah churn (tidak order > 6 bulan)?

## Files
| File | Deskripsi |
|------|-----------|
| task6_customer_baru.sql | Jumlah customer baru per bulan |
| task7_repeat_customer.sql | % repeat customer dan rata-rata jarak antar order |
| task8_cohort_retention.sql | Cohort retention, customer yang kembali bulan berikutnya |
| task9_clv.sql | CLV per customer dan distribusinya |
| task10_churn.sql | % churned customer (tidak order > 6 bulan) |
