# Project 1 — SQL E-Commerce Analysis (Olist Dataset)

## Overview
Analisis dataset Brazilian E-Commerce (Olist) menggunakan PostgreSQL.
Menjawab 20 pertanyaan bisnis di 5 area utama untuk mensimulasikan
pekerjaan data analyst di industri e-commerce.

## Dataset
- Sumber: [Kaggle — Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)
- Periode: 2016–2018
- Ukuran: 100.000+ transaksi, 8 tabel berelasi

## Tools
PostgreSQL, pgAdmin

## Area Analisis

|------|------|------|

| D | Seller | Top seller, seller bermasalah, market share |
| E | Payment | Metode pembayaran, cicilan, pola waktu order |
