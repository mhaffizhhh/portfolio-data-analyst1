# Blok A — Analisis Penjualan

## Business Questions
1. Bagaimana tren total revenue per bulan selama 2016–2018?
2. Kategori produk apa yang menghasilkan revenue terbesar?
3. Berapa kontribusi tiap kategori terhadap total revenue platform?
4. Kategori mana yang mengalami pertumbuhan revenue positif dari 2017 ke 2018?
5. Bagaimana tren Average Order Value (AOV) dari bulan ke bulan?

## Files
| File | Deskripsi |
|------|-----------|
| task1_revenue_per_bulan.sql | Total revenue per bulan + identifikasi tertinggi/terendah |
| task2_top10_kategori.sql | Top 10 kategori berdasarkan revenue, jumlah order, dan AOV |
| task3_kontribusi_revenue.sql | Persentase kontribusi tiap kategori terhadap total revenue |
| task4_growth_kategori.sql | Kategori dengan pertumbuhan revenue positif 2017 vs 2018 |
| task5_aov_per_bulan.sql | Tren Average Order Value per bulan |
